A2 Hosting is now hosting.com — do old A2 coupon codes still work?

Not guaranteed. A2 Hosting rebranded to hosting.com (the brand was acquired by World Host Group and the name changed in 2025). Legacy "A2 Hosting" coupon codes were issued under the old brand and the old checkout, so there is no promise they still validate at hosting.com's checkout. The reliable discount is hosting.com's own current promotion shown on its plan page. If you try a third-party code, the only proof it works is a discount line in your own cart before you pay. What actually changed in the A2 Hosting → hosting.com rebrand

A2 Hosting no longer sells under that name. The brand was acquired by World Host Group and renamed hosting.com in 2025; hosting.com describes itself as the same platform and same team. The change is more than a logo — the checkout brand, the store domain, and the plan lineup all moved with it. That matters for coupons, because a code is tied to the brand, checkout and plan SKUs that existed when it was issued.

Why a legacy "A2 Hosting" code may not work at hosting.com checkout

This is the part most coupon pages skip. A hosting coupon code is not a magic word — it is a key that only opens one specific lock: a promo campaign set up by the brand that issued it, scoped to particular plans and terms, on the checkout it was built for. When the brand renames, the store domain changes, and the plan lineup is replaced, three things can break the key:

  • The brand changed. A code minted for "A2 Hosting" may be scoped to that brand identity, which no longer exists at the point of sale.
  • The checkout moved. The order system that validated the old code may not be the one hosting.com runs today.
  • The plans changed. hosting.com's current shared lineup is Starter / Pro / Max. The old StartUp, Drive and Turbo tiers are gone, so a code tied to a discontinued plan has nothing to attach to.

None of this means every old code fails — but it does mean "it worked on A2 Hosting" is not evidence that "it works on hosting.com." The only test that counts is the one in your own cart.

Where the real discount lives now

The discount you can actually rely on is the one hosting.com puts in front of you: its plan page shows promotional rates that apply when you order. hosting.com's checkout also includes a promo-code field, but it is not a code the official site advertises publicly — so any string you type there has to be proven by the cart, not by a blog post.

hosting.com's own plan page states the things that don't change with a rebrand: a 30-day money-back guarantee, free managed migration, and free domain registration on its entry plan. Those are worth more than a coupon code you can't verify, because they apply regardless of which promo (if any) you use.

How to check any code before you pay (the only reliable test)

  1. Pick your plan and term first. Choose what you actually want on hosting.com before typing anything.
  2. Enter the code in the promo field. A separate discount line should appear in the order summary.
  3. Compare the total with and without it. If there is no discount line, the code didn't apply — you'd pay the listed price.
  4. Check the renewal price too. A first-term code doesn't change what you pay from the second term onward; confirm the renewal figure on the page.
  5. Pay only when the math is real. If the field rejects the code on your plan/term, that combination isn't covered — the listed price is what you pay.

This is also your protection: hosting.com's 30-day money-back guarantee means a code that doesn't deliver what you expected can be walked back within the window.

Where DealDrop, HotDeals and TrulyCodes fall short

The gap this article covers is factual, not a grudge. As of our review (2026-10-13), the three benchmark aggregators still do the following:

  • They keep an "A2 Hosting" store page alive. DealDrop, HotDeals and TrulyCodes each maintain a dedicated A2 Hosting coupon page indexed under the old a2hosting.com identity, listing a set of "active" codes with a headline percentage-off claim — even though A2 Hosting no longer sells under that name.
  • They rarely flag the rebrand. A reader landing on an "A2 Hosting coupon" page isn't clearly told up front that the brand is now hosting.com and that the code may predate the checkout they'll actually use.
  • They don't confirm the code still validates. "Active" on a coupon site means "we haven't removed it," not "we just applied it at hosting.com checkout." The only validation that matters is your cart.
  • They seldom show the renewal rate side-by-side. A first-term code looks generous until you see what the plan renews at — the comparison that actually protects your budget is missing.

That is the gap: searchers want to know "does my old A2 code still work, and where's the discount really?" and the aggregators optimise for a long list of codes rather than answering that question honestly.
