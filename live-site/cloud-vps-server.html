What Is a Cloud VPS Server?

A cloud VPS server (cloud virtual private server) is a virtual machine that runs on cloud infrastructure using KVM (kernel-based) virtualization. The provider carves physical servers into isolated instances; each instance gets a fixed slice of compute — a certain number of vCPUs, a set amount of RAM, and a block of SSD storage. You boot it with Linux (or sometimes Windows), and you get root or administrator access.

The "cloud" part means the underlying hardware is pooled and redundant, and you can usually scale the instance up or down and pay for what you use. The "VPS" part means your resources are private to your instance, unlike shared hosting where many sites compete for the same CPU and memory. Hostinger's official page describes its product as "KVM-based Virtual Private Server"; DigitalOcean calls its instances "Droplets"; Vultr calls them "Cloud Compute"; ScalaHosting calls them "Managed Cloud VPS"; Hetzner calls them "Cloud Servers."

How to Choose a Cloud VPS Server

1. Shared vCPU vs. dedicated vCPU

As Hetzner's official cloud page explains, shared cloud plans share hardware resources with "neighbors" and suit variable or low-traffic workloads; dedicated cloud plans assign dedicated vCPUs to your project for predictable performance. Entry plans from DigitalOcean, Vultr, and Hostinger use shared vCPUs, which a provider can oversell. If you run steady, production-grade workloads, pay for a dedicated vCPU tier.

2. Managed vs. unmanaged

Unmanaged plans (DigitalOcean, Vultr, Hostinger entry) give you a bare Linux server and root access — you patch, secure, and monitor it. Managed plans (ScalaHosting's Managed Cloud) include a control panel, backups, and support for a higher fee. The trade-off is purely your time versus your money.

3. Bandwidth and storage

Included transfer varies widely: DigitalOcean's entry includes 500 GiB of outbound transfer (then $0.01/GiB overage); Vultr's entry includes 0.5 TB; Hostinger's KVM 1 includes 4 TB; ScalaHosting's managed plans list unmetered bandwidth. If you serve large files or media, bandwidth is often the real cost driver, not the vCPU.

4. Location and latency

Pick a region close to your users. Hetzner's cloud runs in Germany, Finland, Singapore, and the US; DigitalOcean spans nine regions; Vultr lists 30+ locations. If data protection law matters to you, Hetzner states GDPR compliance and ISO/IEC 27001-certified German and Finnish data centers.

5. Billing model

DigitalOcean bills per second (minimum 60 seconds or $0.01) as of January 1, 2026; Vultr bills hourly on Cloud Compute. If you spin servers up and down for tests, per-second or hourly billing beats a fixed monthly commitment. Note that some "intro" monthly prices (e.g., Hostinger's $6.49) require a multi-year term and renew higher.

Frequently Asked Questions

What is a cloud VPS server?

A cloud VPS server (cloud virtual private server) is a virtual machine that runs on cloud infrastructure using KVM virtualization. You are allocated a fixed amount of vCPU, RAM, and SSD storage on physical hardware that is shared with other tenants (or, on dedicated-tier plans, not shared). Unlike shared web hosting, your resources are isolated per instance. The providers covered here name it differently: DigitalOcean calls them Droplets, Vultr calls them Cloud Compute, Hostinger calls them KVM VPS, ScalaHosting calls them Managed Cloud VPS, and Hetzner calls them Cloud Servers.

How cheap can cloud VPS cores go right now?

From the providers whose official pricing pages we could verify on 2026-10-15: Vultr's entry Cloud Compute plan is 1 vCPU for $2.50/month (IPv6 only; $3.50/month with IPv4); DigitalOcean's entry Basic Droplet is 1 vCPU for $4.00/month; Hostinger's entry KVM 1 (1 vCPU, 4 GB RAM) is $6.49/month intro on a 2-year term, renewing at $11.99/month. So the cheapest verified 1-vCPU cloud VPS starts at $2.50/month. Hetzner's and Contabo's official pages could not be loaded for automated verification on that date, so we do not state their prices here — check their official sites.

What is the difference between shared vCPU and dedicated vCPU?

As Hetzner's official cloud page states, shared cloud plans share hardware resources with "neighbors" and suit variable or low-traffic workloads, while dedicated cloud plans assign dedicated vCPUs to your project for predictable performance. Many budget VPS plans use shared vCPUs, which providers can oversell. If steady, production-grade performance matters, choose a dedicated vCPU tier.

Is a managed or unmanaged cloud VPS better value?

It depends on the value of your time. ScalaHosting's entry managed cloud VPS is $29.95/month intro (renewing at $54.95/month) and includes server management; DigitalOcean, Vultr, and Hostinger entry plans are unmanaged, meaning you administer the Linux server yourself. If you are comfortable administering Linux, unmanaged at $2.50 to $6.49/month is far cheaper in fees; if your time is valuable, managed may be cheaper overall.

Does the monthly price include everything?

No. Bandwidth, backups, managed support, and control panels are often billed separately. For example, DigitalOcean bills per second with included outbound transfer starting at 500 GiB/month and charges $0.01/GiB overage; ScalaHosting's managed plans include unmetered bandwidth and backups. Always read the official pricing and terms page before buying.

Bottom Line

A cloud VPS server is the sweet spot between shared hosting and a dedicated box: isolated resources, root access, and hourly or monthly billing. If you just want the cheapest verified core today, Vultr's 1 vCPU at $2.50/month (IPv6) and DigitalOcean's 1 vCPU at $4.00/month are the floor we could confirm on 2026-10-15. Step up to Hostinger's 1 vCPU / 4 GB at $6.49/month intro if you want more RAM, or to ScalaHosting's managed Build #1 at $29.95/month if you would rather someone else run the server.

Before you buy, confirm the vCPU type (shared vs. dedicated), the renewal price after any intro term, the included bandwidth, and the data-center region. And if a provider's page fights automated verification — as Hetzner's calculator and Contabo's challenge did for us — open it yourself and read the live number rather than trusting a screenshot or a third-party deal site.
