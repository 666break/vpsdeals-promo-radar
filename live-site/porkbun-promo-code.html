The rejection message, word for word

This is the string Porkbun's cart page displays when the apply call does not succeed. It is not our summary of the rules; it is the text in Porkbun's own front-end file, and it is the only explanation the page gives:

“We were unable to apply the coupon. It may be already applied, it is expired, or the domain or action doesn't qualify for this discount (price too low, premium domain, renewal vs registration, etc).”

Read plainly, the five cases it names are:

  • Already applied — the code is attached to this cart or account already.
  • Expired — the code has passed its own end date.
  • Price too low — the order total is below whatever floor the code carries.
  • Premium domain — the name is priced as premium, so the code does not apply to it.
  • Renewal vs registration — the action is a renewal, not a new registration.

Note what the message does not say: it never states an amount, a percentage, or an end date. Those live on the code itself, not on any page we could open.

Where a code goes, step by step

  1. Put at least one domain in the cart on porkbun.com.
  2. Open porkbun.com/checkout/cart.
  3. Open the dialog titled “apply coupon code” (subtitle: “Do you have a coupon code? That's awesome!”).
  4. Type the code into the field labelled “coupon code” — its input id is cartCouponCode.
  5. Press Enter, or click the “Update Cart” button in that dialog.
  6. If it is refused, you get the message quoted above; if it is accepted, the cart reloads with the code applied.

Why does Porkbun say my promo code can't be applied?

Porkbun's own front-end prints one fixed message when the apply request is not accepted: “We were unable to apply the coupon. It may be already applied, it is expired, or the domain or action doesn't qualify for this discount (price too low, premium domain, renewal vs registration, etc).” That sentence is the complete reason list Porkbun shows, and it names five cases: the code was already applied, the code is expired, the order price is too low, the domain is a premium domain, or the action is a renewal rather than a registration.

Where do I enter a Porkbun promo code?

There is one field, and it is on the cart page, not on the pricing page. Add a domain to the cart, open https://porkbun.com/checkout/cart, open the dialog titled “apply coupon code”, type into the field labelled “coupon code” (its input id is cartCouponCode), then press Enter or click “Update Cart”. The page posts the value to /api/user/applyCartCoupon.

Can a Porkbun promo code be used on a renewal?

Its rejection message explicitly names “renewal vs registration” as a case where the domain or action may not qualify for the discount, so a code aimed at new registrations is the case Porkbun itself flags as likely to be refused. We could not confirm any code that applies to a renewal from an official page.
